Executor Service

Java Concurrency Notes — ExecutorService, Executors, submit(), Future, and FutureTask
Executors ↓ creates ExecutorService ↓ submit(task) Task goes to queue ↓ Available worker thread executes task ↓ Result becomes available ↓ Future / FutureTask ↓ get() ↓ Actual result

1. ExecutorService

ExecutorService is an interface used to manage and execute tasks using one or more worker threads.

Main idea:

Instead of manually creating a new Thread for every task, an ExecutorService manages a pool of reusable threads.

ExecutorService executor = Executors.newFixedThreadPool(3);

executor.submit(() -> {
    System.out.println("Task running");
});

Important ExecutorService methods

MethodPurpose
execute(Runnable)Executes a task. Does not return a result.
submit(Runnable)Executes a Runnable and returns a Future<?>.
submit(Callable<T>)Executes a Callable and returns Future<T>.
submit(Runnable, T result)Executes a Runnable and returns the specified result through a Future.
invokeAll()Executes multiple tasks and waits for all of them.
invokeAny()Executes multiple tasks and returns one successful result.
shutdown()Stops accepting new tasks and lets existing tasks finish.
shutdownNow()Attempts to stop running tasks and returns queued tasks that never started.
isShutdown()Checks whether shutdown has been requested.
isTerminated()Checks whether all tasks have completed after shutdown.
awaitTermination()Waits for executor termination for a specified period.

2. Executors

Executors is a utility/factory class used to create different kinds of executor services.

Executors ↓ creates ↓ ExecutorService

Common factory methods

MethodMeaning
newFixedThreadPool(n)Creates a pool with a fixed number of worker threads.
newSingleThreadExecutor()Creates one worker thread; tasks run sequentially.
newCachedThreadPool()Creates/reuses threads dynamically as needed.
newScheduledThreadPool(n)Supports delayed and periodic tasks.
newSingleThreadScheduledExecutor()Single-threaded scheduled executor.
newWorkStealingPool()Creates a work-stealing pool.

newFixedThreadPool()

ExecutorService executor =
        Executors.newFixedThreadPool(3);
Thread 1 → Task 1 Thread 2 → Task 2 Thread 3 → Task 3 Task 4, Task 5, ... wait in queue. When one thread becomes available, that thread picks the next waiting task.

newSingleThreadExecutor()

ExecutorService executor =
        Executors.newSingleThreadExecutor();
Task 1 ↓ Task 2 ↓ Task 3

newCachedThreadPool()

ExecutorService executor =
        Executors.newCachedThreadPool();

Threads are created when necessary and reused when possible. It can create many threads, so it should be used carefully.

newScheduledThreadPool()

ScheduledExecutorService executor =
        Executors.newScheduledThreadPool(2);

executor.schedule(
    () -> System.out.println("Hello"),
    5,
    TimeUnit.SECONDS
);

3. submit()

submit() is an ExecutorService method that sends a task to the executor for execution.

submit(Runnable)

Future<?> future = executor.submit(() -> {
    System.out.println("Task running");
});

A Runnable does not return a value. Therefore, future.get() normally returns null.

submit(Callable<T>)

Future<Integer> future =
        executor.submit(() -> {
            return 10 + 20;
        });

Integer result = future.get();
Callable<Integer> ↓ submit() ↓ Future<Integer> ↓ get() ↓ 30

submit(Runnable, result)

Future<String> future =
        executor.submit(
            () -> System.out.println("Task running"),
            "SUCCESS"
        );

System.out.println(future.get());

The Runnable itself returns nothing. The value "SUCCESS" is the result provided to submit().

execute() vs submit()

Featureexecute()submit()
Main interfaceExecutorExecutorService
Accepts RunnableYesYes
Accepts CallableNoYes
Returns FutureNoYes
Can retrieve resultNoYes
Can cancel through FutureNoYes

4. Future

Future<T> represents a result that may become available later.

Important correction: Future does not pick a thread and does not execute the task. The ExecutorService and its worker threads do that. Future only represents and gives access to the task's eventual result. 
Future<Integer> future = executor.submit(() -> {
    return 10 + 20;
});
submit(task) ↓ ExecutorService queues task ↓ Worker thread becomes available ↓ Worker thread executes task ↓ Result = 30 ↓ Future represents that result ↓ future.get() ↓ 30

Simple meaning:

Future = "The result may not be ready now, but you can get it later."

Important Future methods

MethodPurpose
get()Waits if needed and returns the result.
get(timeout, unit)Waits only for the specified amount of time.
isDone()Checks whether the task is finished, failed, or cancelled.
cancel(boolean)Attempts to cancel the task.
isCancelled()Checks whether the task was cancelled.

future.get()

Future<Integer> future =
        executor.submit(() -> {
            Thread.sleep(5000);
            return 100;
        });

System.out.println("Before get");

Integer result = future.get();

System.out.println(result);

get() is blocking. If the task is not finished, the calling thread waits.

get(timeout, unit)

future.get(3, TimeUnit.SECONDS);

If the task does not complete within the timeout, a TimeoutException occurs.

cancel()

future.cancel(true);

true means the executor may interrupt the running thread if the task is already executing.

6. FutureTask

FutureTask<V> is a concrete class that implements both Runnable and Future<V>.

FutureTask = Runnable + Future
FutureTask<Integer> futureTask =
        new FutureTask<>(() -> {
            return 10 + 20;
        });

At this point the task exists, but it has not necessarily started.

Thread thread = new Thread(futureTask);
thread.start();

Integer result = futureTask.get();
FutureTask created ↓ Thread runs FutureTask ↓ Callable executes ↓ Result stored inside FutureTask ↓ futureTask.get() ↓ Result returned

FutureTask constructors

FutureTask(Callable<V>)

FutureTask<Integer> task =
        new FutureTask<>(() -> {
            return 50;
        });

new Thread(task).start();

Integer result = task.get();

FutureTask(Runnable, V result)

FutureTask<String> task =
        new FutureTask<>(
            () -> System.out.println("Running"),
            "SUCCESS"
        );

new Thread(task).start();

String result = task.get();

Important FutureTask methods

MethodMeaning
run()Executes the task.
get()Gets the result and waits if necessary.
get(timeout, unit)Waits only for the specified time.
cancel(boolean)Attempts to cancel the task.
isDone()Checks whether execution is finished, failed, or cancelled.
isCancelled()Checks whether cancellation succeeded.
done()Protected callback called when the task reaches a completed state.
runAndReset()Protected advanced method that runs and resets the task.
set(V)Protected method to manually set the result.
setException(Throwable)Protected method to mark the task as failed.

run()

FutureTask<Integer> task =
        new FutureTask<>(() -> 100);

task.run();
Calling task.run() directly does not create a new thread. It runs in the current thread. To run it in another thread, use new Thread(task).start().

get()

FutureTask<Integer> task =
        new FutureTask<>(() -> {
            Thread.sleep(3000);
            return 100;
        });

new Thread(task).start();

Integer result = task.get();

If the task is still running, get() waits until the task completes.

isDone()

if (task.isDone()) {
    System.out.println("Finished");
}

isDone() can also be true if the task failed or was cancelled.

cancel()

boolean cancelled = task.cancel(true);

cancel(true) allows interruption of a running task. cancel(false) does not interrupt a running task.

done()

FutureTask<Integer> task =
        new FutureTask<>(() -> 100) {
            @Override
            protected void done() {
                System.out.println("Task completed");
            }
        };

new Thread(task).start();

8. FutureTask with ExecutorService

ExecutorService executor =
        Executors.newFixedThreadPool(2);

FutureTask<Integer> task =
        new FutureTask<>(() -> {
            return 10 + 20;
        });

executor.execute(task);

Integer result = task.get();

System.out.println(result);

executor.shutdown();

executor.execute(task) works because FutureTask implements Runnable.

task.get() works because FutureTask implements Future.

9. invokeAll()

List<Callable<Integer>> tasks = List.of(
    () -> 10,
    () -> 20,
    () -> 30
);

List<Future<Integer>> futures =
    executor.invokeAll(tasks);

for (Future<Integer> future : futures) {
    System.out.println(future.get());
}

invokeAll() waits for all supplied tasks to complete, unless a timeout overload is used.

10. invokeAny()

Integer result = executor.invokeAny(tasks);

It returns one successfully completed result. You should not depend on which task provides the result.

11. Shutdown

shutdown()

executor.shutdown();
No new tasks accepted ↓ Already submitted tasks continue ↓ Tasks finish ↓ Threads terminate

shutdownNow()

executor.shutdownNow();

It attempts to interrupt running tasks and returns tasks still waiting in the queue. Interruption is cooperative, so a task may continue if it ignores interrupts.

12. Complete Example

import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.Future;

public class ExecutorExample {

    public static void main(String[] args) throws Exception {

        ExecutorService executor =
                Executors.newFixedThreadPool(3);

        Future<Integer> future1 =
                executor.submit(() -> {
                    System.out.println(
                        Thread.currentThread().getName()
                    );
                    return 10 + 20;
                });

        Future<String> future2 =
                executor.submit(() -> {
                    return "Hello";
                });

        Integer result1 = future1.get();
        String result2 = future2.get();

        System.out.println(result1);
        System.out.println(result2);

        executor.shutdown();
    }
}

13. Easy Way to Remember

Executors = factory used to create executor services.

ExecutorService = manages worker threads and task execution.

submit() = submits a task to the executor.

Future = represents a result that may be available later.

future.get() = waits if needed and retrieves the result.

FutureTask = an executable task that also represents its future result.

Executors ↓ ExecutorService ↓ submit() / execute() ↓ Task queue ↓ Available worker thread ↓ Task executes ↓ Future / FutureTask ↓ get() ↓ Result
