# Java Learning Lab

A collection of focused Java examples for learning language fundamentals, object-oriented design, collections, streams, concurrency, and modern Java features through Java 21.

## Requirements

- JDK 21
- Maven (or use the included Maven Wrapper)

## Build

On Windows:

```powershell
.\mvnw.cmd clean package
```

On macOS or Linux:

```sh
./mvnw clean package
```

## Run an example

Each demo is a small Java class with its own `main` method. You can open a class in your IDE and run it directly. For example, after building:

```sh
java -cp target/classes com.example.example.abstractclass.AbstractClass01BasicsDemo
```

Browse the topic folders under `src/main/java` and choose a demo that interests you. Examples are intended to be read and run individually.
